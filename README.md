# Korea Ocean Challenge 웹사이트 시작 키트

## 폴더 구성
- index.html : 웹사이트의 내용(뼈대)
- style.css : 색상과 디자인
- script.js : 메뉴, 복사 버튼 등 기능
- images/ : 활동 사진을 넣는 곳
- docs/ : 가이드북 PDF를 넣는 곳

## 실행 방법
index.html 파일을 더블클릭하면 브라우저에서 바로 열립니다.
(VS Code에서는 "Live Server" 확장 설치 후 우클릭 -> Open with Live Server)

## 꼭 수정해야 할 곳
1. 갤러리 사진 및 대표 사진
2. 소개 글, 일정, 준비물
3. 참가신청/스탭신청 구글 폼 링크
4. 토스 링크
5. 계좌번호, 이메일, 인스타그램
6. docs 폴더의 guidebook.pdf

## 배포 순서
GitHub 저장소를 만들고 파일을 업로드한 뒤 Settings -> Pages에서 main 브랜치를 선택하세요.
